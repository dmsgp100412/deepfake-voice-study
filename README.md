# 훈련 1 AI 음성 판별 실험

훈련 1 음성만 사용하는 익명 청취 실험 웹앱입니다.

- 공개 실험: https://dmsgp100412.github.io/deepfake-voice-study/
- 관리자: https://dmsgp100412.github.io/deepfake-voice-study/#admin

## 실험 흐름

1. 참여 안내와 익명 데이터 저장 동의
2. 성별, 연령대(20대/30대) 선택
3. 훈련 1의 20개 음성 세트를 무작위 순서로 제시
4. 각 세트에서 A/B 음성을 모두 끝까지 재생한 뒤 AI 음성을 선택
5. 확신도 1점부터 5점까지 선택
6. Supabase에 응답 저장

훈련 1 문장:

> 높은 산에 올라가 맑은 공기를 마시며 소리를 지르면 가슴이 활짝 열리는 듯하다.

## 주요 구현 사항

- 음성 파일명은 익명화되어 참가자에게 정답 단서를 노출하지 않습니다.
- 원본 기준 `-1`은 실제 음성, `-2`는 AI/deepfake 음성입니다.
- A/B 위치와 20개 문항 순서는 참가자마다 무작위입니다.
- 기본 오디오 컨트롤을 사용하지 않고 재생 버튼만 제공합니다.
- 음성 길이와 진행 시간은 표시하지 않습니다.
- A와 B를 모두 끝까지 들은 뒤에만 응답할 수 있습니다.
- 반응시간은 마지막 음성 종료 시점부터 AI 음성 첫 선택까지 기록합니다.
- 다시 들으면 마지막 음성 종료 시점이 갱신되고 반응시간 측정도 다시 시작됩니다.

## Supabase

`schema.sql`은 최초 구성용 SQL이고, `training1_update.sql`은 훈련 1 전용 앱에 필요한 추가 컬럼과 RPC 함수 업데이트입니다.

중요 보안 설정:

- `public.stimuli`는 참가자가 직접 읽지 못하게 합니다.
- `submit_trial` RPC가 서버에서 실제/AI 정답 위치를 계산합니다.
- 관리자 조회, 수정, 삭제는 Supabase Auth JWT의 이메일이 `dmsgp100412@gmail.com`일 때만 허용됩니다.

서비스 역할 키나 DB 비밀번호는 저장소에 넣지 않습니다.
