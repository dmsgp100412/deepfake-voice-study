# 훈련 1 AI 음성 판별 실험

현재 공개 앱은 훈련 1 전용 버전입니다. 훈련 1 문장 “높은 산에 올라가 맑은 공기를 마시며 소리를 지르면 가슴이 활짝 열리는 듯하다.”에 대한 20개 음성 세트를 사용합니다.

## 반영 기능

- 실험 참여 동의서
- 성별, 연령대(20대/30대) 응답
- 훈련 1의 20개 음성 세트 무작위 제시
- A/B 위치 무작위화
- 음성 길이를 숨긴 재생 버튼 방식
- A/B 모두 끝까지 들은 뒤 AI 음성 선택 가능
- 확신도 1점부터 5점까지 수집
- 반응시간: 마지막으로 종료된 음성 재생 시점부터 AI 음성 첫 선택까지
- Supabase 저장
- 관리자 이메일+비밀번호 로그인
- 전체 통계, 참가자별 통계, 개인별 응답 상세
- 관리자 응답 편집/삭제 및 참가자 전체 삭제
- Excel(.xlsx) 다운로드
